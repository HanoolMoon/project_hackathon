# 반려동물 건강 분석기 (Pet Health Analyzer)

> AI 기반 배변 이미지 분석으로 반려동물의 건강 상태를 진단하고, GPT가 맞춤형 건강 조언을 제공하는 웹 애플리케이션

---

## 프로젝트 개요 및 목적

반려동물은 스스로 건강 상태를 표현하기 어렵습니다. 이 프로젝트는 반려동물의 배변 이미지를 업로드하면 YOLOv8 기반 컴퓨터 비전 모델이 상태를 자동 분류하고, GPT-4o-mini가 반려동물의 프로필(종류, 나이, 체중 등)과 일상 건강 데이터(식사, 활동, 컨디션, 환경)를 종합하여 수의학적 조언을 제공합니다.

Bristol 분변 척도(1~7단계)를 기반으로 객관적인 건강 지표를 제시하며, 7일간의 건강 추이를 시각화하여 반려인이 반려동물의 건강 변화를 한눈에 파악할 수 있도록 돕습니다.

---

## 주요 기능

### 1. 배변 이미지 AI 분석
- YOLOv8 커스텀 모델로 배변 이미지를 4가지 상태로 분류
  - `normal` (정상), `soft-poop` (무른 변), `diarrhea` (설사), `lack-of-water` (수분 부족)
- Bristol 분변 척도(1~7단계) 자동 매핑
- 신뢰도 70% 미만 예측은 `unknown`으로 처리하고 GPT 조언을 제공하지 않아 오진 방지
- 지원 이미지 형식: JPG, JPEG, PNG, BMP, TIFF, WebP, AVIF, HEIC

### 2. 실시간 AI 건강 조언 스트리밍
- GPT-4o-mini가 수의학 전문가 역할로 맞춤형 조언 생성
- Server-Sent Events(SSE)를 통한 실시간 스트리밍으로 응답을 즉시 확인
- 현재 상태 요약 → 추정 원인 → 즉각 조치 → 병원 방문 필요 여부 순으로 구조화된 답변

### 3. 일별 건강 기록 관리
- 식사·활동·컨디션·환경 정보를 카테고리별로 세분화하여 기록
- 집계 방식: 당일 최악 배변 상태 우선, 산책 시간 합산, 기력·식욕·구토는 최빈값 산출

### 4. 주간 건강 리포트
- 최근 7일간 건강 데이터 시각화 (배변 상태 추이 선형 차트, 산책 시간 막대 차트)
- 기력, 식욕, 구토 여부 등 주요 컨디션 지표 한눈에 확인
- GPT 기반 주간 건강 종합 코멘트 자동 생성 (2~3문장, 친근한 말투)

### 5. 반려동물 프로필 관리
- 이름, 종류(강아지/고양이), 나이, 체중, 중성화 여부, 사료 종류 등록
- 프로필은 브라우저 localStorage에 저장되어 재방문 시 자동 유지

### 데이터 흐름

1. 사용자가 반려동물 배변 이미지와 일일 건강 카테고리 정보를 입력
2. 프론트엔드가 이미지 + 반려동물 프로필 + 카테고리 데이터를 `/analyze-stream`으로 전송
3. 백엔드에서 YOLO 모델로 이미지 분류 → Bristol 척도 매핑 (신뢰도 < 70%이면 `unknown` 처리)
4. GPT-4o-mini가 프롬프트 템플릿 기반으로 수의학적 조언 생성 (SSE 스트리밍)
5. 분석 결과를 `records.json`에 저장
6. 프론트엔드에서 실시간으로 조언 텍스트 렌더링
7. 주간 리포트 화면에서 7일간 건강 추이 시각화

## 설치 및 실행 방법

### 사전 요구사항

- Python 3.9 이상
- Node.js 18 이상
- OpenAI API 키

### 1. 저장소 클론

```bash
git clone <저장소 URL>
cd project_hackathon/pet-health-analyzer
```

### 2. 백엔드 설정

```bash
# 가상환경 생성 및 활성화 (권장)
python -m venv venv

# Windows
venv\Scripts\activate
# macOS/Linux
source venv/bin/activate

# 의존성 설치
pip install -r requirements.txt
```

### 3. 환경 변수 설정

`config/.env` 파일에 OpenAI API 키를 입력합니다:

```env
OPENAI_API_KEY=your_openai_api_key_here
```

> `config/.env` 파일은 `.gitignore`에 포함되어 있으므로 공개 저장소에 노출되지 않습니다. API 키를 직접 코드에 하드코딩하지 마세요.

### 4. 백엔드 서버 실행

```bash
uvicorn api:app --reload --port 8000
```

- 백엔드 서버: `http://localhost:8000`
- FastAPI 자동 API 문서: `http://localhost:8000/docs`

### 5. 프론트엔드 설정 및 실행

```bash
cd frontend

npm install
npm run dev
```

- 프론트엔드 서버: `http://localhost:5173`
- 개발 서버는 `/api` 요청을 자동으로 `http://localhost:8000`으로 프록시합니다.

### 6. 프로덕션 빌드

```bash
cd frontend
npm run build    # dist/ 폴더에 빌드 결과 생성
npm run preview  # 빌드 결과 로컬 미리보기
```

## 사용 방법

### 1단계: 반려동물 프로필 등록

앱 첫 실행 시 온보딩 화면이 자동으로 표시됩니다.

| 항목 | 설명 |
|------|------|
| 이름 | 반려동물 이름 |
| 종류 | 강아지 / 고양이 선택 |
| 나이 | 나이 (년) |
| 체중 | 체중 (kg) |
| 중성화 여부 | 중성화 완료 여부 토글 |
| 사료 종류 | 현재 먹이고 있는 사료명 |

등록된 프로필은 브라우저 localStorage에 저장되어 재방문 시 자동 복원됩니다.

### 2단계: 일일 건강 기록 및 이미지 분석

메인 리포트 화면에서 아래 정보를 입력 후 분석을 시작합니다.

**이미지 업로드**
- 카메라 촬영 또는 갤러리에서 배변 이미지 선택
- 지원 형식: JPG, PNG, BMP, TIFF, WebP, AVIF, HEIC

**건강 카테고리 입력**

| 카테고리 | 항목 |
|---------|------|
| 식사 | 먹은 음식, 식사량, 간식, 물 섭취량 |
| 활동 | 산책 시간(분), 운동량, 활동 장소 |
| 컨디션 | 기력, 식욕, 구토 여부, 체중 |
| 환경 | 날씨, 온도(°C), 스트레스 요인 |

**분석 결과 표시 항목**
- 배변 상태 분류 (정상 / 무른 변 / 설사 / 수분 부족)
- Bristol 분변 척도 (1~7단계)
- 모델 신뢰도 (%)
- GPT 수의학 조언 (실시간 스트리밍)

> 신뢰도가 70% 미만이면 `unknown`으로 표시되며, 이 경우 GPT 조언이 제공되지 않습니다. 더 선명한 사진으로 다시 시도하거나 동물병원에 문의하세요.

### 3단계: 주간 건강 리포트 확인

주간 리포트 화면에서 최근 7일간의 건강 데이터를 확인합니다.

| 항목 | 내용 |
|------|------|
| 배변 상태 추이 | 7일간 배변 분류 결과 선형 차트 |
| 산책 시간 추이 | 일별 산책 시간 막대 차트 |
| 컨디션 지표 | 기력, 식욕, 구토 여부 요약 |
| AI 종합 코멘트 | 7일 데이터 기반 GPT 건강 평가 (2~3문장) |

### 프로필 수정 / 앱 초기화

설정 화면(프로필 수정 버튼)에서:
- 반려동물 정보 수정
- 앱 초기화 (모든 기록 삭제 후 온보딩으로 이동)

## API 엔드포인트

| 메서드 | 경로 | 설명 |
|--------|------|------|
| `POST` | `/analyze` | 이미지 분석 후 CV 결과 + GPT 조언 반환 (동기) |
| `POST` | `/analyze-stream` | 이미지 분석 후 GPT 조언을 SSE로 스트리밍 |
| `POST` | `/record` | 건강 기록 수동 저장 |
| `GET` | `/records` | 날짜별 집계 건강 기록 전체 조회 |
| `GET` | `/weekly-summary` | 최근 7일 데이터 기반 GPT 종합 코멘트 조회 |

프론트엔드는 실시간 응답을 위해 `/analyze-stream`을 주로 사용합니다.

> FastAPI 자동 생성 API 문서: `http://localhost:8000/docs`

## 주의사항

- `config/.env` 파일에 OpenAI API 키가 포함되어 있으므로 공개 저장소에 절대 업로드하지 마세요.
- 이 애플리케이션은 수의학적 조언을 보조하는 도구이며, 실제 수의사 진료를 대체하지 않습니다.
- 배변 이미지의 품질(해상도, 조명, 각도)이 AI 분석 정확도에 영향을 미칩니다.
- 백엔드 서버(`localhost:8000`)와 프론트엔드 서버(`localhost:5173`)를 모두 실행해야 정상 동작합니다.
